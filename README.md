# Viajes Co — Landing Page

Página web de una agencia de viajes donde los usuarios pueden explorar destinos turísticos, tours y paseos, y buscar su próximo viaje.

## Archivos

- `index.html` — Estructura de la página.
- `styles.css` — Estilos de la página.
- `layout_ViajesCo.png` — Layout.
- `imagenes para el css`.

## Secciones

- **Encabezado** con menú de navegación y botón de reserva.
- **Buscador de viajes** con destino, fechas y número de viajeros.
- **Destinos populares** como Cartagena, San Andrés, Santa Marta y Eje Cafetero.
- **Tours y experiencias** disponibles para reservar.
- **Razones para elegir la agencia**.
- **Testimonios** de clientes.
- **Newsletter** para recibir ofertas.
- **Footer** con información de contacto y redes sociales.

## Cómo abrirlo

1. Guarda `index.html` y `styles.css` en la misma carpeta.
2. Abre `index.html` en el navegador.
